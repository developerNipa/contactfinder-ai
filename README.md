# ContactFinder AI

**AI-Powered Business Contact Discovery WordPress Plugin**

ContactFinder AI helps users discover publicly available business contact information from websites.

## Features

- Discover publicly listed email addresses
- Find publicly available phone numbers
- Identify social media profile links
- Scan up to 3 public website pages
- Guest access with a one-website scan limit
- Login and registration for continued access
- Clean and responsive user interface

## Built With

- WordPress
- PHP
- CSS
- JavaScript

## Project Status

Currently under development.

## Security & Privacy

Only publicly available contact information is intended to be discovered. Use the plugin responsibly and respect website terms and applicable privacy laws.
